# JLPT N5 Grammar & Topic Checklist for Anki Flashcards

Use this as a master checklist while building your deck. For each grammar point: check it off, note which textbook chapter/page it came from, and use the suggested card format when you pull example sentences via Copilot/Claude.

**Card format legend** (use consistently so your deck stays uniform):
- **R** = Recognition card (see Japanese → produce meaning/usage)
- **P** = Production card (see English/context → produce Japanese sentence)
- **FB** = Fill-in-the-blank (test the grammar particle/conjugation itself)
- Answer side should always include: correct sentence + 1-line grammar note (not just a translation)

## How to use this with Copilot/Claude for textbook example fetching

Suggested prompt template per grammar point:

> "From [textbook name], find 2-3 example sentences that use the grammar point [X — grammar point + meaning]. For each, give: (1) the Japanese sentence, (2) furigana/reading if needed, (3) English translation, (4) a one-line note on why this sentence illustrates the grammar rule."

Then convert each result into a card using the format column above (R / P / FB).

## Suggested Anki deck structure

- One subdeck per category (e.g. "N5::Particles", "N5::Verb Conjugation")
- Tag each card with the grammar point number (e.g. `n5-particle-14`) so you can filter/study by pattern later
- Keep a running copy of this checklist to track coverage — mark items off as you add cards
